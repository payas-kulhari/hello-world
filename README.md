# Hello World 👋

My first Python repository — written while setting up GitHub for the first time.

## What it does

A small interactive Python script that asks for your name and greets you.

## How to run it

You'll need Python 3.10 or newer.

```bash
python hello.py
```

Then type your name when prompted.

## What I learned building this

- How to install Git and configure my identity
- How to create a GitHub repo and clone it locally
- The basics of `git add`, `git commit`, and `git push`
- Python type hints and docstring conventions
